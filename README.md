# Password Strength Checker & Generator

This is a Python-based project that checks the strength of user passwords and gives suggestions for improving them. It also generates strong passwords for safe use.

##  Features
- Analyze password strength
- Avoids common weak passwords
- Suggests improvements
- Generates strong passwords

##  Technologies Used
- Python
- Regex (`re` module)
- Random password generation
- File I/O

## How to Run

1. Clone/download this repo
2. Make sure you have Python 3 installed
3. Add your own `common_passwords.txt` or use the provided one
4. Run:

```bash
python main.py
